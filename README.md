# OSIRIS 2026 · Reto F1025B

Landing page de expectativa para GitHub Pages, basada en la propuesta visual aprobada.

## Publicación

1. Crea o abre el repositorio de GitHub.
2. Sube **el contenido de esta carpeta** a la raíz del repositorio, preservando `assets/`.
3. Si ya existen archivos con los mismos nombres, reemplázalos. El sitio utiliza `index.html`, `style.css`, `app.js` y los archivos de `assets/`.
4. En **Settings → Pages**, selecciona **Deploy from a branch**, rama **main**, carpeta **/(root)** y guarda.
5. Espera el despliegue y recarga la página.

## Nota

La versión de escritorio utiliza la composición visual aprobada como arte principal, con controles interactivos encima. La versión móvil adapta la composición y muestra texto y botones accesibles. La navegación «El reto» y «Equipo» abre paneles de expectativa, no resultados todavía. El sonido requiere activación mediante clic por las restricciones de los navegadores.
