# OSIRIS 2026 · Reto F1025B
Landing page estática con identidad OSIRIS, estrellas animadas y audio ambiental opcional.

## Publicar en GitHub Pages
1. Crea un repositorio **público** nuevo en GitHub llamado `osiris-2026`.
2. Sube los archivos `index.html`, `style.css`, `app.js` y la carpeta `assets` a la **raíz** del repositorio.
3. Ve a **Settings → Pages → Build and deployment**.
4. Selecciona **Deploy from a branch**, rama `main` y carpeta `/(root)`; guarda.
5. Una vez desplegado, la dirección será `https://TU-USUARIO.github.io/osiris-2026/`.

Abre `index.html` para una vista local. No requiere frameworks ni instalaciones. El audio se activa con el botón porque los navegadores bloquean la reproducción automática.
